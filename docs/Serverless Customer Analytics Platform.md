# Serverless Customer Analytics Platform

## Project Objective

The objective of this project is to collect customer activity data from an e-commerce application and generate business insights using AWS serverless services and data engineering techniques.

## Problem Statement

E-commerce businesses generate large amounts of customer interaction data such as product views, cart actions, and purchases. Analyzing this data helps businesses understand customer behavior and improve decision-making.

## Proposed Solution

The project captures customer events and stores them in Amazon S3. The data is processed using AWS services and analyzed through dashboards to provide meaningful business insights.

## Technologies Used

* React.js
* Flask
* Amazon S3
* Amazon DynamoDB
* AWS Lambda
* AWS Glue
* Amazon Athena
* Amazon QuickSight
* Docker

## Expected Outcomes

* Track customer behavior
* Analyze product popularity
* Identify purchase trends
* Generate analytics dashboards
* Demonstrate serverless data engineering architecture
