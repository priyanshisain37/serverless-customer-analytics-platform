# AWS Services Used

## Amazon S3

Used as a data lake to store customer activity logs and analytics data.

## Amazon DynamoDB

Used as the primary database for storing users, products, and orders.

## AWS Lambda

Used for serverless processing of customer events and automation tasks.

## Amazon Athena

Used to run SQL queries directly on data stored in Amazon S3.

## Amazon QuickSight

Used to create analytics dashboards and business visualizations.

## AWS Glue

Used to crawl and catalog data stored in Amazon S3.

## Amazon CloudWatch

Used for monitoring logs and application performance.

## AWS IAM

Used to manage permissions and access control for AWS resources.
